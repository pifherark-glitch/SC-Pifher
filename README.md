# SC-Pifher
Un carnet de bord pour Star Citizen qui tourne sur ton PC. Pendant que tu joues, le jeu écrit tout ce qui se passe dans des journaux (le fichier Game.log et les anciens dans le dossier logbackups). Personne ne les lit d'habitude : SC Pifher les lit pour toi et en fait un historique clair de tes sessions, trajets, achats, ventes.
